# 计划改进问题

记录日期：2026-11-09

以下六项为当前版本的待改进清单，尚未标记为完成。其中第二项的具体范围待讨论确认。

## 1. AI 绘制的 SVG 图标、图形需要手工调整

- [ ] 逐个检查图标和教学图形，手工调整比例、线条、文字位置、对齐与留白。
- [ ] 检查中英文、横竖屏下的显示，避免文字遮挡、裁切和图形变形。

## 2. 线性回归公式法 or 所有情况（？）

- [ ] 讨论线性回归实验的讲解范围：公式法的适用条件，以及是否展示其他情况和处理方式。
- [ ] 确认需要覆盖的情形后，再确定公式说明、实验交互与边界情况提示。

此项保留原始疑问，目前不预设为“公式法适用于所有情况”。

## 3. 梯度下降只调参不能得到最优解

- [ ] 复现操作过程，检查初始位置、学习率、迭代次数、下降轨迹与最优解判定。
- [ ] 改善参数控制和反馈，明确局部最小值、全局最小值、未收敛及发散的区别。
- [ ] 确保存在可由界面操作达到目标的参数组合，且达到目标后能正确解锁翻页。

## 4. 梯度下降增加函数选项

- [ ] 增加可切换的目标函数，比较不同函数上的梯度下降表现。
- [ ] 函数切换时同步更新公式、图像、梯度计算、参数范围与通关目标。
- [ ] 检查中英文文案与实验状态的切换行为。

## 5. 五子棋白棋颜色在深色模式下的问题

- [ ] 检查系统深色模式、浏览器自动深色显示下白棋和棋盘的实际颜色。
- [ ] 调整棋子填充、描边与对比度，保证黑白棋在不同模式下都可辨认。

## 6. 电脑版底栏有时不固定

- [ ] 复现不同窗口高度、缩放比例及长文页面下的底栏位置问题。
- [ ] 调整桌面端翻页底栏的定位与内容滚动关系。
- [ ] 确保底栏持续可见、内容不被遮挡，并检查横竖屏切换后的布局。
